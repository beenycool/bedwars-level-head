## 2024-10-25 - Refactor `toCSV` to Use Generic Type Parameters
**Tech Debt:** Utilities processing arbitrary collections of objects often relied on `Record<string, unknown>[]`, forcing callers to use `as unknown as Record<string, unknown>[]` when passing domain types (like `ResourceMetrics[]`), bypassing TypeScript's type safety and polluting routes with meaningless casts.
**Learning:** Hardcoding a catch-all type like `Record<string, unknown>` for object arrays pushes the type casting burden to the consumer and weakens type inference.
**Prevention:** Utilities processing collections should be made generic (`<T extends object>(data: T[])`). Type casting should be confined internally to the utility (e.g., `data[i] as Record<string, unknown>`) when dynamically accessing unknown keys, maintaining strict type safety and a clean API for the consumer.
